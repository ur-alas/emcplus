EMC+ is a client-side ONLY modpack that is designed to enhance the player experience on <a href="https://earthmc.net">EarthMC.</a>

For the list of mods that are included, see the [Versions Page](https://modrinth.com/modpack/emcplus/version/0.1.2a)

# 📥 Installation Guide

EMC+ is compatible with all launchers that support .mrpack, though it is only tested with Prism Launcher, and thus its use is recommended.


# 🎯 Goals



### 🚀 Stay lightweight & performant

This modpack is based on Additive (Adrenaline prior to 1.21.11), a lightweight minimal performance modpack. While EMC+ includes many additional Quality of Life mods, they only serve to provide the minimum viable features to maximize players' enjoyment of the server.
Adrenaline provides many benefits, including:
- Faster rendering and logic
- Reduced and optimized memory usage
- More stable framerates

### ⚙️ Source-available

All mods in EMC+ are either open-source or source-available, which means you can view the code of mods and see exactly what they are doing. If you would like to view the mods in EMC+, simply look at the dependencies in the Modrinth page.

# 💡 Main Features
- Excellent performance, thanks to Adrenaline
- Bundled EarthPack for custom server textures
- Most OptiFine features implemented
- Customizable <a href="https://modrinth.com/mod/zoomify">zoom mod!</a>
- Dynamic Lighting
- Chat tabs configured for EarthMC
- Custom main menu featuring community submissions!
